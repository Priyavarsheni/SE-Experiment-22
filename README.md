## Software Engineering Lab

**Experiment 22: Commit Changes Locally and Push Them to GitHub**

### Objective

To learn how to modify a file, commit changes locally, and push them to GitHub.

### Tools Used

* Git
* GitHub

### Description

This experiment demonstrates how to track changes in a project using Git and upload the committed changes to GitHub.

### Commands Used

* git add
* git commit
* git push
